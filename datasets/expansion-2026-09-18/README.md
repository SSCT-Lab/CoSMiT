# 扩大已完成实验：第一批候选准备

本目录承接 `research-data/2026-09-17` 实验。它包含新增公开候选的选择、原代码定位和输入设计。

**当前完成的是 30 条候选、15 个家族的扩充准备；尚未执行新候选，也没有新增反例结论。** 候选未出现在现有 81 条中，但已进行代码审阅，而且部分家族在更早的研究中出现过，因此这是扩充开发批次，不能称为未见家族留出集。

## 阅读入口

- `SELECTION.md`：30 条候选总表，优先阅读。
- `candidates.json`：每条的原始 API、参数、双向代码路径和哈希、上游提交、调用结构、适配需求与特殊边界。
- `input-design.json`：15 个家族的源端输入约束、参考算法设计及 64 输入分层方案；尚未生成数值输入或执行源端资格检查。
- `selection-inventory.json`：1,401 条候选的本批处理状态，包括既有 81 条、选中的 30 条、暂缓变体及未审查条目。
- `protocol-draft.json`：预算与进入正式执行前的要求。不能直接传给现有 v3 runner。
- `manifest.json` / `SHA256.json`：批次统计、旧数据哈希及本目录文件完整性。
- `local-sources/E*/`：本地原始 JSON 和抽出的两侧函数，保持原代码不变。按仓库现有发布边界，该目录不进入 Git；公开清单保留路径、提交和哈希，可用脚本恢复。

## 选择与计数

选择 8 个二元运算家族（16 条）、6 个形状操作家族（12 条）及 clip（2 条），每家族各保留 PT→TF、TF→PT 一条规范入口。clip 用来补充多参数边界；先不接入 sparse、Keras 包装、复杂返回值、随机状态或训练。

候选从既有公开代码中选择，没有人工制造错误，也没有执行后根据错误数量筛选。每条方向算一个候选；相反方向和同族候选相关，不能当作独立统计样本。别名不增加家族数量。库存中的“同名变体”只是暂缓线索，不等同于已经证明语义重复；未选中的其他条目也不是无效候选。

## 下一阶段实现顺序

1. 实现二元 tensor、literal/None、tensor-list 的递归参数编码，保持原函数参数名和代码。
2. 为 shape 操作实现索引／形状参考，并记录 Tensor.view、Tensor.permute、Tensor.squeeze 等实例方法的实际调用；不能只匹配 torch.* 文本。
3. 根据固定版本源规格实现并验证前置条件，生成计划的 64 个不同输入。先验证源端与参考，再冻结输入及容差，最后执行目标。数值容差目前只是提案，不能根据目标结果放宽。
4. 保留源错误、目标异常、未绑定、参考不支持等状态。若需排除候选，记录原因，不能把失败样本静默替换。
5. 每候选 64 输入 × 3 次，计划 5,760 对执行。所有动态比较器使用相同输入；新反例逐条重放审计。
6. 动态流程可靠后再检查模型请求配置。若沿用全部五个模型组件，完整批次是 150 个请求；目前未启动模型调用。

transpose 的默认 perm=None、squeeze 的源端差异、clip 的可选界限均应显式保留为资格检查项。不能因为目标不支持而悄悄从源域删去它们。当前 float32/float64、连续稠密输入也不覆盖混合类型、非连续视图或整个 API 的所有参数。

## 生成和校验

在项目根目录执行；重新生成时使用新的输出目录：

```powershell
.venv/Scripts/python.exe dataset/expansion-2026-09-18/build_selection.py --checkout F:/codes/python/DLLens --output dataset/expansion-new
```

构建脚本不导入框架、不运行第三方函数、不请求模型，并自动创建 SHA256 清单。校验本批产物：

```powershell
.venv/Scripts/python.exe dataset/expansion-2026-09-18/build_selection.py --verify
```

本目录的校验检查代码哈希、函数参数、选择去重和文件完整性；不代表源端可执行性或迁移正确性已确认。
