# 论文写作依据与当前边界

本轮登记实验已完成，可开始撰写问题定义、方法、实验设置、观察结果与局限。公开入口为 [实验数据](../research-data/2026-09-17/README.md)；本地论文正文与主张账本位于 `paper/`，继续不对外发布。

核心问题沿用已经确认的方向：迁移测试能够运行，不代表源性质得到保持；验证应区分无效源测试、无依据的假设、候选不保持和证据不足。数学参照、规格依据及实际执行支持个案结论，模型一致性不作为正确标签。

写作顺序：先完成问题与判定边界，再写已实现的登记条款和执行流程，然后写实际比较方法、相同输入预算和所有失败，最后据结果收敛摘要与贡献。原控制样例、日期库探索和本轮公开API实验分别报告，旧pilot的留出槽与本轮六个未见家族不能混为一组。

RQ1目前有有限域观测与个案反驳，缺少独立正式标签用于总体准确率；RQ2的探针效率优势及RQ3的诊断/条件细化准确性仍缺证据。公共候选的轨迹LLM没有有效主判定，当前比较只能报告可用性失败，不能推导语义准确率。后续若修订提示长度、输出预算或错误诊断，应登记为新协议，不追改这次结果。

现有英文工作稿已同步方法设置、结果表、成本、公开数据范围与局限；它是写作起点，不是投稿就绪稿。后续相关工作新增引用需核验，匿名材料与会议格式在投稿阶段另行处理。
