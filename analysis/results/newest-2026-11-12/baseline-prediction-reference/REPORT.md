# 各基线对照单人标注的初步指标

统一109组，排除D0050。行为94保持/15不保持；意图41保持/68不保持。正类为不保持。所有参考均为单人部分可评标签，尚未完成同域裁决。

## 方法口径

- Direct/Trace LLM分别使用显式behavior_verdict和intent_verdict，不混用总verdict。109组均批次完整；模型输出未决不属于请求失败。
- CoSMiT使用10月19日统一主比较版本，不使用10月25日增加输入的消融Full。它只有登记性质的单一判定，与行为/意图对照均须保留适用范围。
- DLLens是输出差异检查，源容差版本是敏感性对照。与意图标签的表格仅为代理对照。
- DocTer检查输入约束，作为辅助诊断。
- IntentTester Source TDL、Target API、Target TDL扩展是不同验证组件。valid映射为保持/不保持仅作代理分析，不是作者端到端方法性能；Source TDL尤其不是目标迁移质量判断。
- 本次没有自行组合组件或重新运行请求。论文主表不应将不同代理输出无说明地等同为完整意图判定。

## 指标规则

P/R/F1在确定输出上计算，未决正/负类分别报告。全正类召回率=TP/(TP+FN+未决正类)，全样本准确率=(TP+TN)/N，未决不计正确。零分母记N/A，不能填0或100%。不同方法确定输出子集不同，横向比较必须同时看覆盖率及全样本指标。
