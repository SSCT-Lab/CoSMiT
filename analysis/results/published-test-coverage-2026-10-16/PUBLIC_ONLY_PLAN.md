# 仅依靠公开材料的补齐路线

2026-10-16 更新：用户明确不考虑向作者索取。AUTHOR_REQUEST.md 仅作为旧草稿保留，不再是执行路线，也未发送。

## 本轮新进展：Ivy 的现成测试

已固定 [Ivy 提交 a701151c85d59c0260a4dbf505479805bdeec00f](https://github.com/ivy-llc/ivy/tree/a701151c85d59c0260a4dbf505479805bdeec00f)，下载 65 个 TF/PT 前端测试及测试助手文件，无下载失败。通过 AST 检查测试装饰器中的完整 API 字符串，110 个候选中 **80 个找到精确名称对应的公开测试定义**。

逐项入口、函数名和源码行见 [ivy-api-test-leads.json](ivy-api-test-leads.json)。剩余 30 项没有本轮精确匹配；大量是 TensorFlow 顶层 API 与 math 命名空间差异，但不能未经核实就合并计数。

这是“已有公开测试定义覆盖 80 个源 API”，不是“80 对历史迁移测试已找到”，也不是“80 个候选执行成功”。这些测试通过 Ivy 的前端测试助手组织参考实现及后端比较；尚需核实具体后端组合、参数策略、检查规则和依赖版本。Ivy 目标实现与 DLLens 目标实现不同，不能混用旧预测。

## 优先路线一：恢复现有 110 组的差分测试上下文

之前把“没有两个独立 .py 文件”当作难以继续的障碍，标准过窄。测试也可能由输入记录、两侧程序模板及外部 oracle 共同定义。DLLens 的公开代码提供了这一结构：

- `counterpart_agent.py::evaluate_counterpart`：逐输入运行两侧，并比较结果/执行状态。
- `test_sample_inputs`：通过 CounterpartEvaluator 写入实际测试脚本。
- `evaluate_counterpart.py::_generate_tf_code/_generate_torch_code`：使用已有函数、输入、调用和输出序列化组成程序。
- `InputConvertor`：源输入到目标输入的公开转换规则。
- `compare_res`：外部差分 oracle。

因此可以对 110 组做**按公开工件重建的差分测试**，而不重新生成 counterpart。必须保留这一分类，不能宣称恢复了作者历史运行的逐字脚本或新的独立源断言。

### 实施条件及具体步骤

1. 固定每条原始 JSON、作者规则、比较器与版本；对应现有 110 ID。
2. 确认输入转换规则所需依赖完整。公开 evaluator 引用 `Tensor.dtype_list`，但当前下载的 `constraint_solver.py` 中未找到该定义；不能凭经验静默补一个列表后宣称完全复现。
3. 只复用作者规则和已有 counterpart 重建程序，不更改失败输入/函数以让结果通过。新增代码仅负责材料装配、隔离运行、日志和清单；记录每处偏离。
4. 先验证少量代表项：一元、双输入、维度变换、clip 边界。分别记录材料装配成功、语法可解析、源有效、目标可执行和 oracle 结果，避免把这些统计混为一谈。
5. 将通过核查的流程扩展到全部 1,568 条公开输入片段。随机表达式需按作者种子和生成器规则处理；仅设置 NumPy seed 未必控制框架随机数。

这条路线可增加行为保持证据及差分测试目标上下文；如果两侧只共享同一个比较器，不能据此宣称具有足够的独立意图变化样本。意图保持的正负标签仍需来自真实源检查条件与迁移结果的对照。

## 优先路线二：从公开测试和变更记录补充独立意图证据

1. 针对 Ivy 已找到的 80 项，登记测试输入策略、调用、检查器及后端要求，优先检查与现有反例相关的 clip、reshape、transpose、squeeze。
2. 继续核实其余 30 项的 API 别名；别名对应只是寻找测试入口，不代表目标实现相同。
3. 查公开迁移 PR、提交 diff、issue 中的源/目标片段和发布附件。保留迁移出处与原测试标识，不能把两套官方独立单元测试人为配对后称为迁移。
4. CrossProbe 的语法失败样本可以保留为失败迁移；先核实源测试的检查目标和配对出处，不以“不能运行”自动剔除所有失败例。
5. 若找到同 API 的其他真实迁移测试，为其分配独立 test_pair_id 并重跑各方法；110 个 API 候选槽位保留，但原预测只属于原 counterpart。

## 目前不作的承诺

还不能保证完全不做新迁移便找到固定 110 组的全部历史测试对。可执行程序的重建、现成兼容性测试、真实历史迁移测试是三种不同来源，均应保留出处，不能为了覆盖率统一改名。

所有新检索均仅依赖公开材料。尚未运行 Ivy、调用模型或重新迁移测试。
