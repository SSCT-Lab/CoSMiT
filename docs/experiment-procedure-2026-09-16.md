# 论文实验过程

目标：发现迁移后不保持的测试性质，区分无效测试、错误语义假设和有执行支持的违规。TransFuzz仅作方法参考，不参与数值比较。不维护与作者实现的差异清单。

## 研究问题

1. 能否检出普通执行或输出一致性检查遗漏的性质违规，同时控制对有效候选的误拒绝？
2. 能否排除源测试无效、输入不合法、错误oracle/语义假设和不稳定差异，保留有充分证据的反例？
3. 验证需要多少模型调用、执行次数和时间，哪些性质仍无法判定？

搜索策略、修复与条件精化可以作为补充实验，不作为主实验完成的前置条件。

## 数据与执行

收集源测试、目标测试、原输入、断言、版本和完整生成记录。原迁移单测、API对应函数、模型级程序和本研究生成测试分别登记；保留失败和未决。

登记代码哈希、源性质、有效域、输入转换与目标调用。源性质不能根据已找到的目标反例倒推。按源测试、API别名、性质家族和近重复关系分组；组内方向、种子、变体不能跨开发/留出分区。开发集完成输入域与观察规则后冻结，再打开留出集。

所有方法使用同一份候选和具体输入。执行源端并记录断言/错误，然后执行目标端，观察值、形状、dtype及目标调用。源断言无效单列；无法区分环境错误与程序错误时保持未决。

DLLens组件比较对应输出；DocTer检查输入约束；IntentTester核验TDL与API使用，目标TDL检查单独报告；直接LLM和带原始轨迹的LLM形成信息消融。CoSMiT检查登记的源性质，要求同一输入、同一条款、同一源/目标观察在三次真实执行中一致，才确认违规。

当前开发预算每候选两个输入，每输入执行三次，共六对，包含复验。每候选准备五个模型请求：直接判定、带轨迹判定、源TDL、目标API、目标TDL。模型固定配置，不自动重试；新尝试写入独立运行。

共享执行用于控制输入与观察差异，模型成本分别记账。共享执行时间不能冒充各方法的独立原生成本。正式实验报告实际请求/执行量及固定预算内结果。

## 参考判定与结果

参考判定独立于各验证器输出，由源规格、原测试意图和可复验执行提供支持。模型可以辅助解析、核验，模型多数意见不能代替依据。不足时标记未决。用户只复核概念和论证，不必逐条检查数据。

在证据充分的子集统计违规检出、有效候选误拒绝和无效测试/假设排除；公布全体候选中的适用率、未决率、失败率和成本。按源/API组处理相关性，保留所有失败及未决分母。DocTer约束满足率是组件指标，不直接等于意图保持准确率。

输出候选方法矩阵、源组计数、失败与未决清单、证据索引和成本。开发控制只报告功能检查，不计算正式准确率。现有10控制只有1个abs家族。可运行入口见`benchmark/baselines/README.md`。

## 数据获取与源性质阶段（2026-09-16）

公开数据与源性质由代理自行获取、设计、执行核验，无需用户检索或逐条判读。新包 `artifacts/dataset-sources/20260916-v1/` 包含固定版本的 BESSER/TensorScope 材料、24 个数学源性质家族和 69 份 DLLens 公开候选；记录见 `docs/dataset-collection-2026-09-17.md`。

本轮源性质核验预算独立于上述开发 baseline 预算：每个 API 候选 64 个输入 × 3 次真实重复；先运行全部源端，与独立标量数学参照核对，再检查目标。已完成 13,248 对执行，源端全部得到支持，目标 68 份在已测输入上通过、1 份稳定违反值性质。新目标检查当前是源性质数据资格核验，尚未完成全体 baseline 联跑和目标调用观察，不将其命名为正式 CoSMiT 性能。

BESSER 单列模型层，7/10 个源模型完成性质核验，另 3 个保留环境/形状未决；两组配对定义在对齐权重后完成 12 对数值检查。TensorScope 的映射条目不进入候选样本数。API 家族、方向、别名与网络架构分别保留分组信息。

源性质表和输入在目标阶段前保存；整个批次属于发现阶段，不能回称留出集。正式联跑须统一每一数据层的输入预算，为所有方法提供同一候选与观察，并另外冻结未见源组。已取得的数据及未决项均由代理继续处理。

## v3 共同实验后台任务

已将上述 API 资格核验数据接入真实 CoSMiT 条款执行器、目标操作观察和共同 baseline 流程。`benchmark/baselines/protocol-v3.yaml` 固定 69 候选 × 64 输入 × 3 重复、每候选五个模型请求，共 345 请求。源端使用独立数学参照核验，输入域不满足或源假设无效单列。65 个候选找到固定 DocTer 规格，4 个缺失规格保留未决。目标 `1/x` 注册并实测 PyTorch 张量反向除法调用，复合函数观察外层目标 API；不将其说成完整内部操作覆盖。

已通过 19 个测试及 384 对真实适配检查；全量运行由 `run_common_campaign.py` 在后台执行，状态见 `artifacts/baselines/20260916-common-v3/campaign-status.json`。控制组旧 45 个模型请求结束后，再占用两个模型槽运行新 345 请求。该阶段启动不等于全部结果已完成；已探索 24 家族明确排除出未见家族留出，模型层和留出评估另行记录。

v3 的69候选框架阶段已全部结束，13,248对全部完成：CoSMiT与DLLens各检出同一个trunc候选；其余68个在已测输入上支持。对应模型请求尚在队列，见campaign状态文件。新隔离环境下BESSER源性质9/10支持，剩余CNN-RNN在声明token域内不可执行，保留为源域不适用。TensorScope原始转换脚本及192组三端abs验证已完成，不能把该abs样例列为未见组。

未见组另见 `artifacts/baselines/20260916-unseen-v1/protocol.freeze.json`：审计更早开发fixture后，排除sum、mean、transpose、reshape，保留prod、matmul、det、trace、cumsum、cumprod六家族十二候选。登记发生在目标执行前；候选选择、源定义域、输入设计及预算均单独保存。当前仅完成冻结，未执行该留出批次。

未见组现已执行完成框架阶段：12候选、6家族、2,304对，所有源数学参照和目标操作调用得到支持；CoSMiT和DLLens均未发现差异。60个模型请求已准备并排在发现集345请求之后，维持两并发。参考算法与具体输入冻结发生在目标代码查看之前，源域不因目标结果调整。证据：`artifacts/baselines/20260916-unseen-v1/pre-execution-freeze.json`、`adapter-validation.json`及`execution-report/summary.json`。完整实时状态见`docs/full-experiment-status.md`。

BESSER模型层补齐AlexNet/VGG16配对验证：在固定TF2.15/Addons环境下，原公开类保持不变，显式处理NHWC/NCHW输入布局及首个分类器Dense的CHW/HWC权重索引排列；排列规则有独立点积保持测试。两个模型各6对推理执行全部满足值容差、形状和dtype。另记2次目标完整预热、2次源局部特征执行。结合此前tf_tutorial/lstm，四个可运行网络对共24对验证；CNN-RNN保持声明域下源端不可执行，不算目标缺陷。证据：artifacts/baselines/20260916-image-model-pairs-v1/。

## 2026-09-17 本轮登记实验完成

455个主请求与33次限定传输重试均已结束，主结果278有效/177失败，重试补充视图295有效/160失败；独立离线解析视图285有效/170失败，不合并冒充主结果。框架81候选15,552对、BESSER四对网络24次配对推理、TensorScope192组三端执行均结束。最终归档1,462文件哈希通过，模型包53及7文件也通过。

最终结果、方法矩阵、失败列表、成本与局限：`artifacts/baselines/20260917-completion-v1/`；当前状态：`docs/full-experiment-status.md`。上文“未见组未执行”“等待模型槽”等为历史状态，现均已结束。LLM失败仍保留，轨迹分支公共候选无有效判定，不能宣称CoSMiT更准确或FSE证据充分。后续独立标签和有效比较协议是新研究工作，本轮不再自动扩展调用。自动监督收尾后停用。
