## 本地使用

基础项目安装：`python -m pip install -e '.[dev]'`。

可选实验还需要 NumPy、PyTorch、TensorFlow、simplejson 及各实验 README 中指定的版本。完整实验需要自行取得固定版本上游源码。涉及上游 checkout 的测试在材料缺失时跳过；默认单元测试不会调用付费模型。

开发 run、模型请求和复核包均由 `benchmark/rqs/README.md` 中的脚本生成。进展文档中指向 `artifacts/`、生成 JSON 或 `paper/` 的链接是本地证据索引，在 GitHub 上可能不可访问，不应误认为材料已完整发布。
